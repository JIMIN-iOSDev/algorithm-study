\# Algorithm Study

\- 매일 1문제 풀이

\- 주 6문제 진행

\- 동일한 문제를 각자 풀이 후 GitHub에 업로드

\- 서로의 코드를 리뷰하며 다양한 풀이 방법 학습

\## ✅ Git 규칙



\- 자신의 파일만 수정한다.

\- 다른 사람의 코드는 허락 없이 수정하지 않는다.



```

git pull origin master

```



작업 후



```

git add .

git commit -m "week01 문제번호 풀이"

git push origin master

```
